# Ernala Indekost

Frontend mockup untuk Ernala Indekost Cisauk BSD.

## Stack

- React
- Vite
- React Router DOM
- Tailwind CSS
- Radix UI

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Hasil build akan tersedia di folder `dist/` dengan entry `dist/index.html`.
