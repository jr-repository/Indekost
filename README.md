# Ernala Living

Buatkan frontend mockup website lengkap untuk “Ernala Indekost Cisauk BSD” tanpa backend, tanpa database, dan tanpa API nyata. Seluruh konten, akun, kamar, transaksi, booking, survey, tagihan, dan status menggunakan dummy data realistis. Fokus utama pada UI/UX modern, premium, clean, responsive, konsisten, dan production-like, bukan sekadar template generik.

Brand & Design System

Gunakan konsep Modern Warm Living: nyaman, bersih, terpercaya, modern, dan affordable-premium.

Primary: #183D3D Deep Forest

Accent/CTA: #D97855 Terracotta

Secondary: #93A9A1 Sage

Background: #F8F5EF Warm Ivory

Surface: #FFFFFF

Text: #202624

Secondary text: #6E7471

Border: #E6E8E5

Font heading: Manrope

Font body/UI: DM Sans

Card radius 16px, input/button 10px, shadow sangat subtle

Gunakan spacing system konsisten berbasis 8px

Terracotta khusus action/CTA, Forest untuk branding/navigation, Ivory untuk environment/background

Hindari UI terlalu ramai, gradient berlebihan, glassmorphism ekstrem, dan tampilan admin-template generik

Gunakan foto properti, kamar kos, interior, common area, lifestyle, dan lingkungan BSD/Cisauk dari Unsplash, Google Images, Pexels, atau sumber placeholder publik yang relevan. Pastikan seluruh halaman memiliki visual/image asset yang sesuai.

UX Requirements

Buat seluruh navigation dan interaction mockup dapat diklik dan berpindah halaman. Form, filter, modal, dropdown, booking flow, survey flow, payment flow, check-in, complaint, maintenance, extend stay dan check-out harus memiliki simulasi state menggunakan dummy data.

Pastikan Public Website, Tenant Portal dan Admin Portal terasa sebagai satu design system Ernala yang sama, tetapi public lebih visual/lifestyle, tenant lebih personal dan functional, sedangkan admin lebih dense dan operational.

Prioritaskan hasil akhir yang terlihat seperti produk SaaS/property management modern yang benar-benar siap dikembangkan, dengan responsive desktop/tablet/mobile, hierarchy visual kuat, typography rapi, whitespace cukup, reusable components, consistent icons dan micro-interactions halus.
